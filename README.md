# CRUD Users

Aplicação Full Stack para gerenciamento de usuários, desenvolvida com React no frontend e Node.js no backend, utilizando MongoDB para armazenamento dos dados.

O projeto tem como objetivo praticar o desenvolvimento de aplicações Full Stack, integração entre frontend e backend, criação de APIs REST e operações com banco de dados.

## 🚀 Tecnologias utilizadas

### Frontend
- React
- JavaScript
- Axios
- CSS

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose

## ✨ Funcionalidades

- [x] Cadastrar usuários
- [x] Listar usuários
- [x] Excluir usuários
- [ ] Editar usuários
- [ ] Validação de formulários
- [ ] Tratamento de erros

## ⚙️ Como executar o projeto

### Pré-requisitos

- Node.js
- npm
- MongoDB

### 1. Clone o repositório

```bash
git clone https://github.com/theluquinhass/CRUD-Users.git
```

### 2. Configure o Backend

```bash
cd CRUD-Users/backend
npm install
```

Configure a variável de ambiente de conexão com o MongoDB no arquivo `.env`, conforme o nome esperado pela aplicação.

Inicie o servidor:

```bash
npm run dev
```

### 3. Configure o Frontend

Em outro terminal:

```bash
cd CRUD-Users/frontend
npm install
npm run dev
```

Acesse a aplicação pelo endereço disponibilizado pelo Vite no terminal.
